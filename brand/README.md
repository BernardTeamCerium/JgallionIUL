# J Gallion Financial: brand kit

Colors and type taken from **jgallionfinancial.com** and **jadengallion.com** (reviewed October 2026), as used on the IUL landing page.

## Logo files

| File | Use |
|---|---|
| `jg-monogram-gold.png` | Gold JG monogram, transparent (original from jgallionfinancial.com) |
| `jgallion-logo-horizontal-navy.png` | Monogram + "J GALLION FINANCIAL" wordmark, for light backgrounds |
| `jgallion-logo-horizontal-white.png` | Same lockup, for navy/dark backgrounds |
| `jgallion-icon-512-navy.png` | Square app / social profile icon |
| `favicon.ico`, `favicon-64.png` | Browser tab icons (from jgallionfinancial.com) |

## Colors

| Role | Hex | Source |
|---|---|---|
| Deep navy (dark backgrounds) | `#0A0F19` | jgallionfinancial.com background |
| Navy (headings, buttons) | `#0F172A` | jadengallion.com navy |
| Gold (on dark) | `#CFB068` | jgallionfinancial.com gold |
| Gold gradient | `#BC974E` → `#DEC782` | jgallionfinancial.com buttons |
| Brass (gold text on light) | `#A07D3E` | jadengallion.com brass |
| Light brass | `#CBB07B` | jadengallion.com |
| Page background | `#FBFBFA` | jadengallion.com |
| Alt section background | `#F4F2EC` | jadengallion.com |
| Body text | `#475569` | jadengallion.com |
| Borders | `#E8E5DD` | jadengallion.com |

## Type

- Headlines: **Playfair Display** (jadengallion.com). jgallionfinancial.com uses Cormorant Garamond for display type.
- Body: **Plus Jakarta Sans** (jadengallion.com).
